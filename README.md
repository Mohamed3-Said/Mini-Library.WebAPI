## 📚 Mini Library Management System API
**Tech Stack:** ASP.NET Core Web API, EF Core, SQL Server, Onion Architecture  

A RESTful API to manage library operations such as books, users, employees, and borrowing records.  
- Implemented Onion Architecture with Repository & Unit of Work  
- CRUD operations for all main entities  
- Used AutoMapper for DTO mapping  
- Documented & tested endpoints with Swagger and Postman
